# Bidrag til Eksamensprojekt

Tak fordi du overvejer at bidrage til dette projekt! For at sikre kvalitet og stabilitet i main-branchen, bedes bidrag følge nedenstående retningslinjer.

---

## Commits

- Hold commits små og fokuserede.  
- Skriv meningsfulde commit-beskeder, der klart beskriver ændringen.

## Test

- Sørg for, at alle tests kører lokalt inden push eller oprettelse af pull request.  
- Tilføj nye tests for nye funktioner, hvis det er relevant.

## Issues

- Projektet har potentiale for videreudvikling. Opret en issue med dine idéer.
- Opret en issue, hvis du støder på en fej 
- Beskriv problemet eller idéen tydeligt og inkluder gerne relevante kodeeksempler.

## Pull Requests

- Aldrig kode direkte i main branch.
- Opret pull requests fra en ny feature- eller bugfix-branch til main.  
- Link til relevante issues i pull request-beskrivelsen.  
- Beskriv ændringerne klart og kortfattet.

## Kodeformat og stil

- Følg eksisterende kodekonventioner for sproget, der bruges i projektet.  
- Sørg for, at koden er læsbar, veldokumenteret og let at forstå.
